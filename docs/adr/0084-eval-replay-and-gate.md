# 0084 回放评测：用例与快照、防泄漏、统计与发布门禁

## 背景

DESIGN §14 要求在自己的事件上、按自己的模型量出准确率：两种回放（snapshot 只读固化的查询邻域，reconstructed 在保留期内重新查询）分开报告；防止答案泄漏；按集合与粒度评分；置信区间用聚类自助法；发布门禁按配对比较。

## 决定

1. **契约**：`contract/schemas/eval-case.schema.json`（标准答案、标准答案来源、防泄漏、领域包时序）与 `eval-snapshot.schema.json`（研判上下文与查询快照）。查询快照沿用领域包 `pack test --replay` 的 `srenautix.io/query-snapshot/v1`，评测与领域包测试使用同一种 VCR 格式。`eval-report.schema.json` 增加 pass@1、运行一致性、覆盖率、选择性准确率、可靠性表、服务方指纹与门禁的配对字段。
2. **snapshot 模式**：只读工具换成快照工具：同一操作、同一查询文本、录制范围覆盖请求范围时命中，结果裁剪到请求范围；其余请求返回"不可用"并计入未命中率。工具描述中列出快照录制过的查询，模型可以据此选择。**reconstructed 模式**使用配置的只读 MCP 工具，只读当前状态的工具不可用，时间范围限定在快照窗口内。两种模式的成绩在报告中分开。
3. **防泄漏**：回放的研判输入不含该事件的任何反馈；知识条目的 `learned_from` 与用例的 `learned_from_keys` 有交集时排除；参考案例只保留用例开始之前已解决的，并排除本事件、别名与同根因的模型生成结论；被排除的材料逐条记录（用例浏览器展示）。成绩按领域包早于或晚于事件分组。
4. **评分**：top-1 落在根因集合内为命中；召回@3 为前 3 个候选（结论在前，其余按账本状态，不含被推翻的）覆盖集合；按粒度分组；处置判断按标准答案；结论为 inconclusive 或 undetermined 算弃权，计算覆盖率与选择性准确率。benign 用例以"处置为 ignore 且没有 evidence_consistent"为正确，出现 evidence_consistent 计为误报；abstain 用例（去掉根因组件上的异常卡的反事实快照）以弃权为正确。
5. **统计**：每个比例都给出分子、分母与聚类自助法 90% 置信区间：以用例为聚类有放回抽样（同一用例的多次运行整体进出），统计量为抽中用例的分子之和除以分母之和，2000 次，固定种子。可靠性表给出每个结论档位的精确率；evidence_consistent 的精确率下界低于 0.85 时标记降级。
6. **发布门禁**：两份配置在相同用例上各运行 k 次（默认 3），按用例配对：基线 pass^k 通过、候选不通过的用例必须为零或逐条豁免（`--waive`）；按用例的正确率差（候选减基线）的平均值做自助法，单侧 90% 下界不低于阈值（用例数 n < 100 时 −10 个百分点，否则 −5 个百分点）。
7. **命令**：`srenautix eval --cases <目录> --config <配置>`、`srenautix eval --compare <当前配置> <候选配置>`，`--runs 3`，报告写到 `eval/reports/`（Markdown、JSON 与逐次运行记录）。`srenautix eval import-seed` 导入旧版 Ops-Agent 的回放种子。
8. **用例目录**：`cases/<case_id>@<version>.json` 与 `snapshots/<snapshot_id>.json.zst`（zstd 压缩的 JSON），读写时按契约校验；同一用例以最大版本为准。

## 结果

- 统计函数用确定性的合成成绩表测试（点估计、区间与正态近似的一致、聚类区间宽于独立样本区间、门禁的两条规则与两档阈值）。
- 完整评测（场景用例与它的 abstain 反事实用例）在本地 Qwen3 1.7B 上运行并录制，回放测试断言成绩单、可靠性表与门禁；同一份录制作为候选时配对差为零、门禁通过。
