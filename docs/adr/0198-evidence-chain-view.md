# 0198 证据标签页：按论证分组的证据链

状态：已采纳

## 背景

事件详情的证据标签页把卡按「异常、无法判定、正常」平铺。在真实事件上有四个问题：

- **看不到结论引用的卡。** 标签页取 `GET /v1/incidents/{ref}/evidence?run_id=`，这个接口只返回区分性检查产生的卡。假设引用的阶段 A 卡（例如 38 张里的 32 张）不在页面上，假设标签页里的 `card:<n>` 链接也跳不到任何地方。
- **看不出卡和结论的关系。** 卡上没有写它被哪个假设引用、是支持还是推翻；假设标签页只写引用编号，不写卡的标题与取值。
- **图读不出信息。** 每条序列单独画一张 48 像素高、没有坐标轴的图。一张卡有 7 条序列就是 7 张图，其中即时查询的单点序列是空白；图上没有单位、阈值的数值、异常从什么时候开始、告警在什么时候触发。
- **契约里的判定依据没有显示。** 证据基线（`novelty`，这次的值和事件之前的时段相比是否平时就有）、求值过的条件（`conditions`）、观测值（`observations`）与参数（`params`）都在结果里，页面没有用。

## 决定

### 1. 证据的来源

一次研判的全部证据（模型所见）是该研判所在事件版本的阶段 A 卡加它的检查卡，由 `runEvidence`（`apps/srenautix/src/incident/read.ts`）给出。研判明细 `GET /v1/runs/{run_id}`、证据快照 `GET /v1/incidents/{ref}/evidence?run_id=` 与实时重跑 `POST /v1/incidents/{ref}/evidence/rerun` 都用它。实时重跑带 `run_id` 时校验研判属于这个事件。

事件详情用研判明细里的 `evidence`（带序列）加 `output.check_cards`，证据快照只补其中没有的卡（`mergeEvidence`）。没有完成的研判时用最新阶段 A 的卡。

### 2. 分组

`buildEvidenceChain`（`packages/ui/src/domain/evidence-chain.ts`，纯函数）按卡在论证里的位置分组，组内按判定与编号排序：

| 组 | 条件 | 默认 |
|---|---|---|
| 结论依据的证据 | 结论采用的假设列为支持的卡，以及为它做的检验 | 展开 |
| 与结论相反的证据 | 结论采用的假设列为推翻的卡 | 展开 |
| 其他假设用到的证据 | 只被其他假设引用 | 新出现的异常展开，其余一行 |
| 没有被假设引用的异常 | 异常，证据基线不是常态 | 展开 |
| 平时也成立的异常 | 异常，证据基线为常态（`novelty.status = routine`） | 一行 |
| 无法判定 | 无法判定或能力缺失 | 一行 |
| 检查过，没有异常 | 正常 | 一行 |

没有研判输出时只有后四组。收起的卡是一行：判定、标题、实体、主值、理由。

### 3. 证据链概要

标签页顶部是一块概要：

```mermaid
flowchart LR
  o[最早的异常<br/>带那张卡] --> f[告警触发] --> c[研判结论] --> r[恢复]
```

下面是结论：结论级别、根因、采用的假设的机制（标注模型生成）、它的支持卡、相反卡与检验卡、没有满足的结论条件、其他假设各自的状态。卡的引用用同一个组件 `EvidenceRefChip`：写出判定、标题、主值与编号，点击后展开并滚动到这张卡。假设标签页用同一个组件，点击时切换到证据标签页。

### 4. 一张卡

展开的卡依次是：引用它的假设（支持、相反、检验）、主值与阈值、理由、证据基线、图、表、判定依据、查询。

- **证据基线**：是否平时就有（平时没有、平时也这样、基线不足）、判定说明，以及各对照时段与本次的主值和判定。
- **图**（`cardCharts`）：同一个查询引用的序列画在一张图里，按取值不同的标签命名，最多 8 条（`SERIES_SLOTS`，按峰值取）；只有一个点的序列不画图。图带坐标轴，x 轴是卡的窗口；阈值是带数值的虚线，异常时段（`anomaly_started_at` 到窗口结束）是底色，告警触发是竖线。悬停时列出该时刻每条序列的值，同一页的图共用十字线。
- **单位**：卡只声明主值的单位与一条阈值，没有声明它们属于哪个查询。单位是 `percent`、`ratio` 时只用于取值在比例范围内的图，其他单位只用于与阈值同一数量级的图；不适用的图用紧凑数字，不画阈值。
- **判定依据**：求值过的条件（命中、未命中、没有求值）与 CEL、观测值、参数。

### 5. 序列的颜色

设计令牌新增 `series-1` … `series-8`：固定顺序的分类色，浅色与深色各一套，Grafana 插件用同一套。相邻两色在色觉障碍下可区分（CVD ΔE ≥ 8）。浅色的 3、4、5 号对白色背景的对比度低于 3:1，所以多序列的图一律带图例与悬停读数。只有一条序列的图按判定着色。

## 后果

- 证据快照接口带 `run_id` 时返回的卡变多（加上阶段 A 的卡），与接口说明「模型所见的快照」一致。
- 实时重跑一次最多 50 张卡（接口上限），按分组顺序取前 50 张。
- 单位与阈值适用于哪张图是按数值推断的；要准确，需要卡片定义为每个查询声明单位（契约变更）。
