# 0071 控制台的路由、页面状态与实时数据

## 背景

控制台的页面需要可以分享与刷新：值班人员把收件箱的过滤结果、事件详情的某个标签页发给同事，对方打开后应当看到同样的内容（DESIGN §12.2"过滤条件保存在 URL 中"）。数据随事件流变化，页面要及时反映，但不能每个组件各自轮询。

## 决定

1. **路由**：TanStack Router 的代码路由。每个页面的 search 参数都有类型与校验函数，全部可选；链接只写要改的字段，默认值由页面补齐，非法取值被丢弃。集群切换写在每个页面的 `cluster` 参数里。
2. **登录守卫**：受保护的路由在 `beforeLoad` 中读取会话（`GET /v1/auth/session`，401 视为未登录），未登录时跳转到 `/login?return_to=<原地址>`；`return_to` 只接受站内路径。
3. **数据**：TanStack Query。查询键集中定义（`qk`）。事件流的每种事件对应要失效的键（`invalidationKeys`，按前缀失效；详情页以 URL 里的引用为键，所以事件详情相关的事件让全部 `['incident']` 前缀失效）。控制台用 `EventSource('/v1/events')`，断线后浏览器带 `Last-Event-ID` 续传；每次重新连上时整体失效一次，补上断线期间可能漏掉的事件。另外每 60 秒全量对账一次（DESIGN §2.3）。插件后端不代理长连接，插件每 15 秒对账。
4. **写操作**：会话认证；CSRF token 取自会话响应，由 openapi-fetch 的中间件附加在非 GET 请求上。H 档审批前，本地管理员在抽屉里输入口令与 TOTP 调用 `/v1/auth/reauth`，OIDC 用户跳转到 `oidc/start?max_age=0` 再回到审批页；合规配置下审批时用 `@simplewebauthn/browser` 对中心生成的挑战签名，断言随审批请求提交。
5. **个人偏好**：语言、主题、时区存在浏览器的 localStorage；组织级的默认值在设置页（服务端）。
6. **构建**：elkjs（约 1.4 MB）在第一次绘制根因子图时按需加载。

## 结果

- 页面状态都能通过 URL 复现，e2e 测试直接断言 URL。
- 事件流断开时页面不会停在旧数据：重连后全量刷新，此外有 60 秒的对账兜底。
