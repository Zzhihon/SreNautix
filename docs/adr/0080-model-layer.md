# 0080 模型层：方言档案、结构化输出与修复阶梯、熔断与故障域

## 背景

DESIGN §8 要求模型层同时适配 OpenAI 的两种协议（`/v1/responses` 与 `/v1/chat/completions`），覆盖前沿模型、DeepSeek、vLLM 上的 Qwen 等私有化模型；结构化输出在各服务方之间能力不一：有的支持严格 `json_schema`，有的只有 `json_object`，有的把推理内容放在独立字段，有的内联在正文。模型服务本身可能就是这次事故的一部分。

## 决定

1. **路由与方言档案**：每条路由（契约 `ModelRoute`）声明 base URL、协议、模型、方言档案、单价、`failure_domain`、`in_domain`、档位（small / large）。方言档案（契约 `DialectProfile`）记录严格 `json_schema`、原生工具、推理通道（`none` / `separate_field` / `inline_tags`）、上下文长度、中文能力、分词器。内置声明档案只作为起点：worker 启动时（`llm.probe_on_start`）和评测时逐项探测，探测结果覆盖声明值并保存在 `worker.route_state`；服务方不公开的项（例如上下文长度不在 `/models` 中）沿用声明值，并在探测报告里标为 `declared`。
2. **两种协议都经 `openai` SDK**：内部消息模型映射到两种请求体；`responses` 不在服务方存储（`store: false`）。支持严格 schema 的方言用 `json_schema`（strict），其余用 `json_object` 并把 schema 写进系统提示。推理内容只计长度，不约束、不进入结论。
3. **可移植 schema 子集**：`contract/model/` 的两个 schema 必须扁平、全部必填、`additionalProperties: false`、只用枚举、不用 `oneOf`（运行时与测试都检查）。`x-srenautix-dynamic-enum` 字段在每次运行时替换为本次运行的取值（组件、证据引用、检查模板、runbook、动作）。发给模型的是只含子集关键字的版本；本地校验用保留长度与条数约束的完整版本。动态枚举为空时，可空字段只允许 null，不可空字段所在的数组只能为空。
4. **修复阶梯**：解析 → jsonrepair → 校验 → 按字段挽救（删除不合格的条目、截断超长文本、可空字段置 null）→ 带上错误重新请求一次 → 换下一条路由 → 只出确定性报告并标注"模型输出无效"。每一级的结果按阶段与路由计数（`srenautix_llm_repair_total`），每次调用的 `repair_step` 写入运行明细。
5. **档位**：`hypothesize` 与 `conclude` 先用大模型路由，其余（只读工具结果的判定、"仍然一致"）先用小模型；对应档位没有可用路由时用另一档。
6. **熔断**（所有研判共用）：失败型为 60 秒内 5 次失败（网络、超时、408、429、5xx）打开，打开后每 30 秒放行一次探测；延迟型为最近调用的 p50 超过单次超时的一半时打开。请求本身被服务方拒绝的 4xx 不计入熔断，但会换下一条路由。
7. **故障域提前熔断**：事件涉及的组件（成员组件与候选根因）落在某条路由的 `failure_domain` 内（组件键相同，或组件在声明的命名空间伪组件之下）时，这条路由对本次研判视为打开；全部路由都被这样打开时阶段 B 跳过，只出阶段 A。全部路由都声明了被管拓扑内的故障域时，worker 启动时告警并置状态条件。
8. **单次调用超时**默认 90 秒，且不超过阶段 B 剩余时间；剩余不足 5 秒时不再调用。
9. **服务方指纹**：服务方返回的模型 ID 与 `system_fingerprint` 组成路由指纹；新指纹连续出现 3 次才确认变化，确认后计数告警并保存，该路由的回放成绩作废，直到重新评测。

## 结果

- 同一份研判代码可以在严格 schema 与非严格 schema 的服务方之间切换，失败的方式在每一级都可度量。
- 模型层测试使用 OpenAI 官方 OpenAPI 描述中的响应示例，以及在本地 llama.cpp（Qwen3 1.7B）上录制的真实响应。录制时观察到 llama.cpp 的 `/v1/responses` 不执行 `text.format` 中的 `json_schema`（`/v1/chat/completions` 执行），测试固定了这一事实；能力探测按实际输出判定，所以同一个服务在两种协议的路由上可以得到不同的档案。
- 前沿模型服务的能力只在运行时探测：仓库里没有它们的录制响应，相关取值以探测报告为准。
