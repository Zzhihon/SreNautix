# Security Policy

SreNautix is in the design stage and has no released code yet.

To report a vulnerability, including a flaw in the design that would break one of the safety invariants in [POSITIONING.zh-CN.md](POSITIONING.zh-CN.md), use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository. Please do not open a public issue.

You will get an acknowledgement within 7 days.
